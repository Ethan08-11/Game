# 新卡牌专属效果

记录需胜利解锁的收藏卡（及图鉴样例卡 `T-01`）当前专属效果。费用、部门、卡牌类型不变。效果以结构化配置为准，下文描述与库内 `cards.description` 一致。

**范围：** `O-16`～`O-19`、`S-07`～`S-24`、`P-05`～`P-20`、`O-20`～`O-44`、`T-01`、`H-01`～`H-03`、`B-01`～`B-08`  
**不含：** 初始 27 张旧卡（`S-01`～`S-06`、`P-01`～`P-04`、`O-01`～`O-15`、`L-01`/`L-02`）

Word 版见同目录 `新卡牌专属效果.docx`。自 2026-08-24 起新增的卡改记入 `新卡牌专属效果（第二版）.docx`。表格列为：编号、名称、费用、类型、专属效果、设计说明。

**设计原则**

- 整套机制（类型 + 时机 + 延迟 + 数值 + 目标）互不重复，也不复刻旧卡整套。
- 公共卡强度按费用：0 费≈2、1 费≈3、2 费≈4、3 费≈6。
- 老板卡同费明显高于公共卡（约高一档费用）。
- 销售偏输出，采购偏防御，公共可混搭；目标「自己 / 一名玩家 / 双方」视为不同效果。



# 游戏规则

**剧情**
顾客长期遭受bully者欺凌，于是雇佣HIH保护自己。HIH销售部与采购部共同出战，与bully者展开对战，直到击败对方或己方全员倒下。


## 一、游戏目标与失败条件
   **胜利条件：** HIH销售部与采购部的血条均大于0，且bully者血条小于等于0，则游戏胜利。
   **失败条件：** 销售部或采购部任意一人的血条小于等于0，则立即判定玩家失败。

**bully者攻击值设定：** 基础攻击为第1–2回合5点、第3回合6点、第4回合7点、第5回合及以后8点。

**顾客机制：**
顾客会始终在作战现场。每回合进入玩家回合前，进行一次顾客机制判定，有40%的概率触发顾客机制；未触发时，本回合不产生额外效果。

顾客机制触发时，在以下两种机制中随机选择一种，两种机制的触发概率相同，各为50%：
1. 血条变化：随机使bully者血条增加或减少2–5点。增加或减少方向的概率相同，各为50%；具体数值在2–5点之间随机。
2. 攻击变化：随机使bully者攻击值增加或减少2–5点。增加或减少方向的概率相同，各为50%；具体数值在2–5点之间随机。

**顾客机制的结算顺序：** 每回合玩家出牌前先判定并结算顾客机制；随后进行玩家出牌。若顾客机制使bully者血条降至0或以下，则不进入玩家出牌阶段，直接进行玩家胜利结算。若顾客机制使任意玩家血条降至0或以下，则不进入玩家出牌阶段，直接进行玩家失败结算。

**结算规则：** bully者结算时，攻击值对所有血条大于0的HIH成员分别造成等量伤害，结算后攻击值归零。伤害先扣除防御，剩余部分再扣除血条；血条降至0或以下的成员倒下，不再行动或受到伤害。


## 三、职业与初始牌库
    职业选择：采用双人协作对战模式 ，玩家开局前二选一选择销售部/采购部职业 ，匹配对应职业的专属牌组 ，不可重复选同一职业。
    卡牌使用限制：销售部卡牌仅销售部玩家可使用； 采购部卡牌仅采购部玩家可使用； 其他部门卡牌（公共跨部门牌）所有玩家公共使用。
    初始牌堆：单职业初始牌堆共20张 ，开局每人发5张手牌。
    销售部：从12张销售部牌中抽6张 + 从30张其他部门牌中抽14张。
    采购部：从8张采购部牌中抽4张 + 从30张其他部门牌中抽16张。

## 五、回合流程（每回合严格按序执行）

### 阶段一：开局准备

1. 两位玩家分别选择销售部和采购部职业，不可选择相同职业。
2. 游戏开局时，系统为每位玩家从52张总牌库中随机抽取20张，作为其本局固定个人牌堆。
3. 每位玩家从自己的牌堆中抽取5张作为首回合手牌，并获得3点员工调用机会。

### 阶段二：玩家回合

1. 进入玩家回合前，先检查两位玩家血条。若销售部或采购部任意一人的血条≤0，则不进入玩家回合，直接进行玩家失败结算。
2. 顾客机制在每回合玩家出牌前判定。若本回合触发，则先随机执行一种顾客机制；若未触发，则直接进入玩家出牌阶段。
3. 顾客机制结算后再次检查胜负：若bully者血条≤0，则不进入玩家出牌阶段，直接进行玩家胜利结算；若任意玩家血条≤0，则不进入玩家出牌阶段，直接进行玩家失败结算。
4. 若双方均未触发胜负条件，则销售部与采购部共同进入出牌阶段。两位玩家可自行决定出牌顺序，并在各自员工调用机会限制内打出卡牌。
5. 出牌期间遵守职业限制：专属卡牌仅对应职业可打；两位玩家可以沟通，但不可查看对方手牌。
6. 两位玩家完成出牌后，点击“结束回合”按钮。点击后立即停止所有玩家出牌，未打出的手牌全部进入各自弃牌堆，未使用的员工调用机会清零。
7. 点击“结束回合”后立即检查bully者血条：
   - 若bully者血条≤0，则不进入bully者回合，直接进行玩家胜利结算。
   - 若bully者血条>0，则进入bully者回合。

### 阶段三：bully者回合

1. bully者根据当前攻击值对两位玩家分别造成等量伤害。伤害优先扣除玩家防御；防御不足时，剩余伤害再扣除玩家血条。
2. bully者完成攻击后，处理持续效果与“下回合”效果，并清除到期标记。
3. bully者回合结束后，立即检查两位玩家血条：
   - 若销售部或采购部任意一人的血条≤0，则直接进行玩家失败结算，不再进入下一个玩家回合。
   - 若两位玩家血条均>0，则进入下一玩家回合。

### 阶段四：下一回合准备

1. 每位玩家从自己的牌堆中抽取5张作为新手牌，并获得3点员工调用机会。
2. 当个人牌堆耗尽时，立即将该玩家的弃牌堆洗牌，并作为新的个人牌堆继续抽取。
3. 按照“顾客机制判定 → 玩家回合 → 检查bully者血条 → bully者回合 → 检查玩家血条”的顺序循环，直到触发胜利或失败结算。
4. 本局游戏结束前，个人牌堆构成不再变动，仅依赖弃牌堆循环复用各自的20张牌。
## 六、特殊状态与平衡提⽰
    持续效果：“持续两个回合”指本回合+下回合开始阶段；到期移除。
    血条恢复：所有原“增加信心值”效果均改为恢复指定玩家的血条。仅可恢复血条>0的HIH成员，且不可超过各自上限（销售部15，采购部20）；已倒下成员不可被恢复。
    玩家防御：所有原“增加抗压值”效果均改为增加指定玩家的防御。防御用于抵挡伤害，受到伤害时先扣防御，防御不足的部分再扣血条；防御最低为0。
    攻击伤害：攻击值只会对血条大于0的成员造成伤害，并按照“先防御、后血条”的顺序结算。
    顾客机制概率：每回合有40%概率触发；触发后，“改变bully者血条”和“改变bully者攻击值”各占50%。选定机制后，增加与减少各占50%，变化数值为2–5点随机值。
    胜负判定优先级：顾客机制结算后立即检查胜负；bully者血条≤0时直接胜利，不再进入玩家出牌或bully者回合。玩家点击“结束回合”后再次检测bully者血条，bully者血条≤0时直接胜利且不执行其回合；bully者回合结束后检测玩家血条，任意玩家血条≤0时直接失败且不进入下一玩家回合。
    战略核心：销售部主要削减bully者血条，采购部主要增加玩家防御；必须保证两位玩家均存活，并在bully者行动前将其击败。其他部门卡兼顾血条恢复和资源辅助。
    资源管理：员工调用机会不可跨回合累积，务必每回合精打细算，优先使用0费卡，高费卡需计算当回合收益。
